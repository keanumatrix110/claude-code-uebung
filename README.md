# Claude Code Übungsprojekt

Ein kleines Repository, um den Pull-Request-Workflow auf GitHub zu üben.

## Über dieses Projekt

Dieses Repo enthält ein winziges Python-Skript zur Begrüßung sowie einen
passenden Test. Es dient als Sandkasten für erste Schritte mit Git, GitHub
und Pull Requests.

## Nutzung

```bash
python greet.py Welt
```

## Tests

```bash
python -m pytest
```

## Budgetplaner

Im Ordner [`budget-planner/`](./budget-planner) liegt eine eigenständige
Web-App: ein Budgetplaner mit Dashboard, Budget-Kategorien, Diagrammen und
Buchungsverwaltung. Siehe [`budget-planner/README.md`](./budget-planner/README.md)
für Details.
