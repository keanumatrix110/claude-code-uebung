# Budgetplaner

Eine moderne, ästhetische Web-App zum Planen und Verfolgen des persönlichen
Budgets — Einnahmen, Ausgaben, Budget-Kategorien mit Limits und Trends auf
einen Blick.

## Funktionen

- **Dashboard** mit Einnahmen, Ausgaben, Saldo und Sparquote (inkl. Vergleich
  zum Vormonat)
- **Budget-Kategorien** mit Limits und Fortschrittsbalken, die bei
  Überschreitung deutlich markiert werden
- **Diagramme**: Ausgabenverteilung nach Kategorie (Donut) und Verlauf über
  6 Monate (Balkendiagramm)
- **Buchungen** anlegen, bearbeiten und löschen (Einnahme/Ausgabe, Betrag,
  Kategorie, Datum, Notiz)
- **Monatsnavigation**, um vergangene Monate einzusehen
- **Hell-/Dunkelmodus**
- Alle Daten werden lokal im Browser gespeichert (`localStorage`) — kein
  Server nötig

## Tech-Stack

React, TypeScript, Vite, Tailwind CSS, Recharts, Zustand, lucide-react.

## Entwicklung

```bash
npm install
npm run dev
```
